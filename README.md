# Assignment 4 — Forms and Validation

A small multi-page front-end project showing HTML forms, HTML5 validation, Bootstrap styling, and validation feedback.

## Pages

- **Task 0 — Simple Contact Form** (`index.html`): name, email, message, submit, and connected labels.
- **Task 1 — HTML5 Form Validation** (`validation.html`): `required`, `type="email"`, `minlength`, and `maxlength`.
- **Task 2 — Bootstrap Contact Form** (`bootstrap.html`): `form-control`, grid columns, placeholders, and helper text.
- **Task 3 — Bootstrap Validation Feedback** (`feedback.html`): JavaScript adds `is-valid` / `is-invalid` to show feedback text.
- **Task 4 — Registration Form** (`registration.html`): full registration fields, responsive grid, validation, matching passwords, and reset.

## How to run

1. Download or clone the repository.
2. Open `index.html` in a browser.
3. Use the top navigation menu to visit each task.
4. Internet access is needed to load Bootstrap from its CDN.

## Publish on GitHub Pages

1. Push all files to a GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/(root)` folder, then save.
5. Add the published site URL to your repository description or this README.

## Technology

HTML5, CSS3, Bootstrap 5.3, and vanilla JavaScript.
